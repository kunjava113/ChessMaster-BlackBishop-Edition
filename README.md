# Chessmaster Black Bishop Edition

A standalone Chess game engine and application developed by **Xpresspo5TV** and hosted by kunjava113. Originally built using **Python** and compiled into a standalone Windows executable (`.exe`).

No Python installation required! Anyone can download and play the game directly on Windows.

## Project Details
* **Developed By:** Xpresspo5TV
* **Format:** Standalone Windows Executable (.exe)
* **Core Language:** Python
* **Features:** Custom Python chess logic, Black Bishop movement mechanics, and portable gameplay.

## How to Play
1. Download the executable file from this repository.
2. Double-click the `.exe` file to launch the game instantly.
